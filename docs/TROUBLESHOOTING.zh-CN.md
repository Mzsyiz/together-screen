# 故障排查

[English](TROUBLESHOOTING.md) | 简体中文

## 无法打开网站或登录

检查 Node 服务：

```bash
curl http://127.0.0.1:3000/api/health
systemctl status together-screen
```

确认：

- `APP_ORIGIN` 与协议、域名和端口完全一致；
- HTTPS 证书有效；
- 只有 HTTPS 环境使用 `COOKIE_SECURE=true`；
- 反向代理转发 `/api` 和 `/ws`；
- 使用 Nginx 或宝塔时设置 `TRUST_PROXY=true`。

## 登录成功但无法进入房间

一个账号只能有一个活跃浏览器客户端。在新浏览器、标签页或设备登录会让旧页面失效。需要时刷新旧页面并重新登录。

## 无法共享屏幕

`getDisplayMedia()` 需要安全上下文：

- 生产环境使用 `https://`；
- 本地开发使用 `http://localhost`。

推荐桌面版 Chrome 或 Edge。

## 远端视频黑屏

当前客户端会让 WebRTC 视频持续播放，并用首帧覆盖空闲画面。如果仍然黑屏：

1. 悬浮画面，确认是否显示实时预览。
2. 检查共享端是否意外停止了共享。
3. 查看浏览器 Console 和 `chrome://webrtc-internals`。
4. 确认共享窗口仍然存在且不是受保护内容。
5. 换一个浏览器或窗口来源测试。

不要公开上传原始 WebRTC dump，其中可能包含 IP 和网络元数据。

## 画面模糊

检查画质状态：

- “首帧”表示只显示静态图片；
- “轻量预览”本身就是低码率、约 360p；
- 只有共享端确认参数生效后才显示“高清”。

如果长时间停在“正在切换高清”，可能是共享端浏览器不支持请求的编码参数，或编码负载过高。

静态桌面会显得实测码率很低，因为编码器可以高效压缩不变画面。应先使用运动或游戏画面测试，再判断是否需要增加带宽。

## 画面延迟或卡顿

可能原因：

- 共享者上传带宽不足；
- TURN 中继吞吐不足；
- Wi-Fi 丢包；
- 浏览器编码负载；
- 同时高清共享的路数太多。

可尝试：

- 降低分辨率或使用“省带宽”；
- 一次只请求一路高清；
- 关闭其他占用视频采集的标签页；
- 使用有线网络；
- 检查 TURN 端口和服务器出口限制。

## 无法加入语音

检查浏览器权限：

1. 点击地址栏中的站点图标。
2. 允许麦克风。
3. 确认其他软件没有独占麦克风。
4. 修改系统麦克风权限后刷新页面。

必须使用 HTTPS。除 localhost 外，不安全上下文会阻止麦克风。

## 语音已连接但没有声音

检查：

- 房间声音按钮没有被静音；
- “语音输出音量”大于零；
- 远端成员没有静音；
- 浏览器输出设备正确；
- 系统没有单独把浏览器音量调低。

语音设置面板会显示成员连接状态和说话指示。

## P2P 连接失败

严格网络中需要 TURN。公共 STUN 只负责地址发现，不转发媒体。

检查：

```bash
ss -lunpt | grep 3478
turnutils_stunclient turn.example.com
```

同时确认系统防火墙和云安全组都允许 UDP 中继端口。

## 火山引擎 WTN 失败

检查：

- 服务端已经配置 `WTN_APP_ID` 和 `WTN_APP_KEY`；
- 切换媒体模式时房间必须为空；
- 房间卡片和房间顶部显示“火山 WTN”；
- WTN 控制台已经开启推流鉴权和拉流鉴权；
- 服务端 AppKey 与 WTN 应用一致；
- 浏览器可以访问 `wtn.volcvideo.com`；
- 服务器时间准确，因为 JWT 使用 Unix 过期时间；
- 房间没有超过 WTN 计费或并发限制。

浏览器不能获得 `WTN_APP_KEY`。WTN 请求失败时查看响应状态和浏览器 Network 面板，不要在公开 Issue 中粘贴完整 JWT。

如果 WTN 返回 `Invalid RID`，系统会回退到 WTN 默认视频层。观看不会中断，画面角标显示“WTN 默认质量 · 兼容预览”。当 WTN 应用和发布 SDP 正确暴露兼容的 `Low` / `High` RID 后，会自动恢复低清和高清切换。

## 设置弹层不显示

升级后强制刷新：

```text
Ctrl + Shift + R
```

设置弹层必须脱离底部控制栏的裁切上下文。浏览器缓存的旧 CSS 可能导致弹层不可见。

## SQLite 错误

- 确认 `DATA_DIR` 存在且服务用户可写。
- 不要让多个应用实例同时使用同一个 SQLite 目录。
- 同时备份 `app.sqlite`、`app.sqlite-wal` 和 `app.sqlite-shm`。
- 恢复时必须先停止服务。

## 诊断信息

WebRTC 问题可提供：

- 浏览器和版本；
- 房间人数；
- 直连还是 TURN；
- RTT、丢包、jitter、freeze 次数和 codec；
- 内容是静态还是运动；
- 分辨率、FPS 和码率；
- 服务器地区以及是否使用 TURN。

发布前必须隐藏公网 IP、内网 IP、Cookie、账号和 TURN 凭证。
